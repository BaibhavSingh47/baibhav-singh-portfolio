## ⚙️ Run Locally

Make sure Node.js and npm are installed, then run:

```bash
npm install
npm run dev
```

The development server will normally be available at:

```text
http://localhost:5173/
```

## 📦 Production Build

```bash
npm run build
npm run preview
```

The production build is generated in the `dist` directory.
